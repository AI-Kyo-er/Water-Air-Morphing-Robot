# 潜空智航：水空跨介质智能航行器

**面向多模态巡检的约束协同控制与视觉感知**

## 一、项目背景

浅水区域巡检往往需要先跨过陆岸距离抵达目标，再在水下进行近距离观测。水空跨介质平台把
空中快速到达能力与水下精细作业能力结合，在应急搜救、环境监测、水利设施巡检等场景具有
应用价值。

团队前期已完成双速倾转水空原型：双速减速箱、倾转机架、防水结构与整机装配，并完成过
空中、水中及出水过程测试，以及声磁采集、深度温度读取、视觉识别和声呐扫描等单项功能
验证。本项目在这些基础上，把机械平台升级为能自主感知、决策与控制的跨介质智能系统。

## 二、研究目标与内容

系统按"大脑—小脑—执行器"分工：树莓派作为大脑负责感知与任务决策，飞控作为小脑负责
运动控制与执行量分配，推进与倾转单元负责执行。研究围绕两条主线展开。

### 主线一：空气/水下工况的约束联合分配

倾转角、推力与推进效能共同决定平台可实现的力与力矩，且随介质变化。研究在介质推力边界、
执行器幅值与变化率、已知推力效能等约束下的联合分配问题，采用逐次线性化与有界最小二乘
求解，并通过状态监督实现介质切换时的指令连续过渡（无扰切换）。在 INAV 飞控上二次开发
水下运控模态，与空中模态共享姿态估计与执行链路；执行链路由 ESP32 驱动倾转舵机。

### 主线二：树莓派视觉检测链与双介质自主任务流

在树莓派上构建 YOLO 视觉检测链（ONNX Runtime / OpenCV），结合目标跟踪与图像质量评估，
并联合声磁等证据做可信融合。任务层协调空中抵达、入水巡检、目标确认与出水返航，自动
生成速度、航向与高度/深度目标，通过"大脑—小脑"接口驱动双介质自主运动。

## 三、关键问题

1. **可达执行空间内的运动分配。** 平行倾转构型没有直接横向推力，局部秩至多为五，需要在
   任务轴优先级下处理幅值、速率与效能约束，避免在边界处产生指令跳变。
2. **介质切换的连续性。** 空中与水下动力学差异大，切换瞬间若增益或倾转指令跳变，会引起
   姿态扰动，需要无扰过渡与限速。
3. **退化观测下的可靠判定。** 传感器存在干扰、缺失与更新延迟，需要质量与新鲜度加权以及
   相关证据折扣，输出稳定的目标判定供任务层使用。

## 四、技术路线与实现

| 模块 | 内容 | 位置 |
|---|---|---|
| 推进几何与动力学 | 推力方向映射、控制效率矩阵、六自由度集总模型 | `control/cm_uav/` |
| 约束控制分配 | 逐次线性化 + 有界最小二乘，含速率与效能约束 | `control/`、`firmware/inav/` |
| 飞控二次开发 | 水下运控模态、双套 PID 无扰切换、SBUS 下发 | `firmware/inav/` |
| 执行链路 | SBUS 解析、镜像标定、指令限速与失联保护 | `firmware/esp32/` |
| 视觉检测链 | YOLO 推理、目标跟踪、图像质量、方位输出 | `perception/vision/` |
| 可信融合 | 校准、质量与时间权重、相关分组 | `perception/fusion/` |
| 任务与导航 | 任务状态机、占据地图、A* 与局部动态窗口 | `autonomy/` |

控制分配在基准场景上覆盖常规机动、偏航、效能下降、快速指令与介质切换，并给出基线对比与
消融；视觉—任务—导航链在统一入口下端到端回放。所有结果可由 `scripts/` 下的脚本复现。

## 五、创新点

1. 面向介质与执行器约束的倾转联合分配：把独立舵角、推力效能、介质边界与变化率约束统一
   到任务加权分配问题，以逐次线性化与有界最小二乘求解，支持介质切换的指令连续过渡。
2. 视觉检测驱动的跨介质自主任务组织：以树莓派视觉链与可信融合支撑目标确认，用"大脑意图
   —小脑控制—执行反馈"接口连接感知与运动，形成双介质自主运动流程。
