# 原型参数与来源

| 参数 | 当前值或记录 | 来源与状态 |
|---|---|---|
| 整机质量 | 3.65 kg | 原结项报告记录；后续载荷变化需重称 |
| 单推进单元最大空气推力 | 约 1.4 kgf；模型用 13.7 N | 原报告记录与单位换算；需保留台架记录 |
| 倾转操作限幅 | ±60° | 原始 ESP32 程序，当前研究/固件沿用 |
| 舵机镜像方向 | `[+,+,-,-]` | 原始角度到脉宽程序 |
| 浅水无线控制 | 报告记载 0.5 m 内可控制 | 历史测试条件，不能扩大为耐压深度 |
| 双速减速比 | 不同版本材料出现 13 与 35 | 对应版本需依据实物齿数确认，不统一写成单个已测值 |
| 水下最大单桨推力 | 模型用 16 N | 设计估计，待台架标定 |
| 惯量 / 排水体积 / 阻尼 | 配置中的估计值 | 尚无完整辨识记录 |
| 推进单元安装位置 | 模型用四角 ±0.30 m | 建模参数，待实物几何测量 |
| 倾转变化率 | 90°/s | 开发采用值，待舵机负载标定 |
| 推力变化率 | 80 N/s | 研究采用约束，待推进台架标定 |

配置与实机参数是相互映射的两个层次。后续用台架和称量结果更新
`control/configs/vehicle_default.yaml` 与 `firmware/esp32/include/config.h`。

深度传感器量程、整机防水耐压与通信控制深度分别记录。
原 PPT 的深度计参数存在单位不一致，未把该页参数用作整机能力指标。

SBUS 模式通道：原始代码使用 `data.ch[10]`，重构配置使用零起始索引 `9`。
需要按实际遥控器映射复核，不能仅依据 CH10 的口头名称判断接线。
